#### 1. 🧾 Student Grade & Result System

### Create a program that takes a student's details and marks in 5 subjects and generates a complete result.

## Requirements:
# Take student's name, roll number and marks of 5 subjects.

# Calculate:
# Total marks
# Percentage
# Average

# Assign a grade:
# 90+ → A+
# 80–89 → A
# 70–79 → B
# 60–69 → C
# 50–59 → D
# Below 50 → F

# Determine whether the student has passed or failed.
# A student must score at least 35 in every subject to pass.
# Display a neat result report.

## Concepts covered:
# input(), variables, typecasting, arithmetic operators, if-elif-else, strings, comparison operators.
